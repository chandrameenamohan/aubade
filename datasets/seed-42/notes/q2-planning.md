# Q2 planning

Three themes came out of the session: depth in the plant-floor integrations, a real onboarding path that does not need a human, and enough security paperwork to stop losing mid-market deals at procurement.

The argument was about the second one. Tomás wants the onboarding work first because it unblocks self-serve; Priya wants the integrations first because they are what the reference customers actually renew on. Both are right and only one can be first.

Resolution: integrations lead, onboarding follows in the same quarter with a smaller scope than originally drawn.

Headcount assumption behind all of it is two engineers and a designer. If the designer loop stays where it is, the onboarding scope is the thing that gives.
